-   Web sitesi doğrudan ekranınızda açılır.
-   Web siteleri çevrimdışı çalışmaz; bu uygulamayı kullanırken kesintisiz internet bağlantınız olmalıdır.
-   Web sitesinin adresini kopyalayın.
-   Panele giriş yapın.
-   Çalma listesine, ardından web sitesini ekleyeceğiniz katmana tıklayın.
-   Katmanda medya yoksa uygulamalar penceresi açılır. Varsa **Add New** düğmesine tıklayın.
-   **Web** seçeneğine tıklayın.
-   **Website** seçeneğine tıklayın.
-   Kopyaladığınız adresi kutuya yapıştırın.
-   **Save** düğmesine tıklayın.
