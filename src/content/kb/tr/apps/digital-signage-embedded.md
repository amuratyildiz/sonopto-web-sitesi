-   HTML kodunu kopyalayın.
-   Panele giriş yapın.
-   Çalma listesine, ardından gömülü HTML kodunu ekleyeceğiniz katmana tıklayın.
-   Katmanda medya yoksa uygulamalar penceresi açılır. Varsa **Add New** düğmesine tıklayın.
-   **Web** seçeneğine tıklayın.
-   **Embedded HTML** seçeneğine tıklayın.
-   HTML kodunu yapıştırın.
-   **Save** düğmesine tıklayın.
-   Sayfanızı önizleyin.
